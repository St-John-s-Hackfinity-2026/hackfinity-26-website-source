# Hackfinity ’26 Event Details

## Confirmed event date

Hackfinity ’26 — **TOOFAN: The Narco Hunt** is scheduled for **9 October 2026**. The live registration website and organization-owned GitHub Pages preview both calculate their public countdown against **9 October 2026 at 00:00 IST (UTC+05:30)**.

| Public surface | Date behavior |
|---|---|
| Full registration website | Shows the live countdown and accepts registrations. |
| GitHub Pages visual preview | Shows the same countdown but does not submit registrations or display live server data. |

The organizer may update this date in `client/src/pages/Home.tsx` by changing the `LAUNCH_TIMESTAMP` constant and the visible countdown label together.
